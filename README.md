# BTU AI Skills Digital Passport

https://btu-ai-passport-gamma.vercel.app/

ეს პროექტი შეიქმნა BTU-ს ჰაკათონისთვის. მისი მიზანია სტუდენტების მიერ მიღებული AI უნარების ციფრული პასპორტების (PDF) ავტომატური გენერაცია, ვერსიების მართვა და მათი ნამდვილობის ბლოკჩეინზე გადამოწმება.

## რას აკეთებს სისტემა?

1. **მონაცემების მიღება:** Google Sheets-ში დადასტურებული უნარის დამატებისას, ბექენდი ავტომატურად იღებს ახალ ჩანაწერს.
2. **PDF-ის შექმნა/განახლება:** სისტემა აგენერირებს სტუდენტის პასპორტს. ფაილის უხილავ მეტამონაცემებში იწერება ვერიფიკაციის ID.
3. **ბლოკჩეინზე ჩაწერა:** ფაილის გაყალბების თავიდან ასაცილებლად, მისი SHA-256 ჰეში ინახება EVM სმარტ-კონტრაქტში.
4. **ნამდვილობის შემოწმება:** საიტზე PDF ფაილის ატვირთვისას, სისტემა თავიდან ითვლის ჰეშს და ადარებს ბლოკჩეინზე შენახულ ორიგინალს. დოკუმენტში თუნდაც ერთი სიმბოლოს შეცვლა ვერიფიკაციას აგდებს.

## ტექნოლოგიური სტეკი
* **სერვერი & UI:** Next.js (App Router), TypeScript, Tailwind CSS
* **Blockchain:** Solidity, Ethers.js, Polygon Testnet
